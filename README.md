# Playwright_AbhishekM

Playwright test automation project.

## Setup

```bash
npm ci
npx playwright install
```

## Run tests

```bash
npx playwright test
```

## Reports

- Playwright HTML report: `npx playwright show-report`
- Allure (if configured): generate/open based on your project scripts
